01 Overview

What the A1860 is for

Intended purpose, in plain terms, before the mechanics.

INTENDED PURPOSE

Quantitative & qualitative immunoassay

Automated chemiluminescence immunoassay analyzer for in vitro diagnostic use — infectious disease markers, tumor markers, sex hormones, thyroid hormone, and related analytes from serum, plasma, or urine.

MODEL FAMILY

A1800 / A1820 / A1860 / A1880

Same core engine, different configuration. The A1860 carries an external barcode scanner and 24-position sample racks, but does not have automatic water emptying — that distinction matters for shutdown planning below.

Operator scope — this instrument is to be operated only by personnel trained and authorized by Autobio. This reference supports that training; it doesn't replace it.
02 Working Principle

Magnetic particle separation + chemiluminescence

The detection chemistry that everything else in this reference — sample flow, incubation, flags — is built around.

STEP 1–2

Complex formation

Antigen/antibody-coated magnetic particles react immunologically with an enzyme-labeled antigen/antibody conjugate, forming the antigen–antibody complex to be measured.

STEP 3–4

Substrate reaction → photon capture

The enzyme-labeled complex catalyzes the luminescence substrate, emitting photons. A photometer records the photon energy, and the system converts light intensity to analyte concentration.

04 Operating Guidelines

Daily running, cleaning, shutdown

The sequences that actually protect result quality and instrument lifespan.

Daily clean (before the day's run)

  • Sample probe internal + external wash — ≥10 cycles
  • B/F wash station — ≥20 cycles
  • Substrate line wash — ≥60 cycles at 50 µL/cycle
  • Don't interrupt the cleaning run — stopping mid-cycle risks database or operation faults

Daily maintain (after the day's run)

  • Runs automatically after testing completes, before software shutdown — no manual action needed by default
  • If manually triggered: sample probe ≥10 cycles, B/F wash ≥20 cycles
  • Continuous-run labs: perform after the longest idle period, not just once daily

Daily shutdown

  • Confirm status is Ready / Not Ready / Offline — never during Running or Pause
  • Run daily maintain
  • Remove all sample racks and containers
  • Remove and refrigerate all kits
  • Empty large-capacity waste containers
  • Clear solid waste containers, then power down instrument + computer

Long-term shutdown (> 5 days)

  • Contact Autobio technical support first to confirm the exact process for your unit
  • Run BF Emptying, then Close Software → Shutdown Computer → Shutdown Instrument
  • Swap substrate bottles and wash buffer for purified water, run the water-loading/emptying cycle
  • Confirm no residual liquid in sample probe, magnetic wash, or substrate lines before leaving it
Temperature gate — if incubation tray, reagent carousel, substrate, or cleaning/metering temperatures haven't reached their normal range, the system will not start detection — this is by design, not a fault to work around.
