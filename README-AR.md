# موقع طلبات روت دياجنوستيك — دليل الرفع على Hostinger

يعمل على الاستضافة المشتركة (Premium أو Business) بدون VPS: PHP 8.x + MySQL.
الزائر يملأ النموذج ويضغط واتساب أو "أرسل الطلب عبر الموقع". الطلب يُحفظ في قاعدة البيانات ويصلك إيميل، ويظهر في لوحة الأدمن.

## 1) قاعدة البيانات
1. hPanel → Databases → Management → أنشئ قاعدة MySQL جديدة ومستخدمًا لها.
2. سجّل: اسم القاعدة، اسم المستخدم، كلمة السر. (الأسماء بتبدأ غالبًا بـ u123456789_)

## 2) إيميل الإرسال
1. hPanel → Emails → أنشئ حسابًا على دومينك، مثل orders@yourdomain.com.
2. هذا هو `mail_from`. أما `admin_email` فهو الإيميل اللي هتستقبل عليه الطلبات (ممكن Gmail).

## 3) رفع الملفات
1. hPanel → File Manager → public_html (أو مجلد الدومين الفرعي).
2. ارفع محتويات الـ ZIP كلها كما هي، وفك الضغط.
3. تأكد أن ملف `.htaccess` ظاهر (فعّل Show hidden files).

## 4) إعدادات الاتصال
عدّل `config.php`:
- db_name / db_user / db_pass من الخطوة 1 (db_host يبقى localhost)
- admin_email و mail_from من الخطوة 2
- wa_number رقم واتساب بصيغة دولية (مضبوط على 201013174996)

## 5) التثبيت (مرة واحدة)
1. افتح: https://yourdomain.com/install.php
2. اختر اسم مستخدم وكلمة سر قوية (10 حروف أو أكثر). تتخزن مشفّرة (bcrypt).
3. بعد "تم التثبيت" احذف `install.php` من File Manager فورًا.

## 6) الاستخدام
- النموذج: https://yourdomain.com/
- لوحة الأدمن: https://yourdomain.com/admin/login.php
- في اللوحة: بحث وتصفية، تغيير الحالة (جديد / قيد التنفيذ / تم)، رد على واتساب، اتصال، حذف.

## 7) SSL
hPanel → Security → SSL → فعّل SSL المجاني للدومين. الـ `.htaccess` بيحوّل HTTP إلى HTTPS تلقائيًا.

## اختبار نهائي
- [ ] أرسل طلب تجريبي من موبايل → يظهر في اللوحة
- [ ] وصل إيميل الطلب (افحص Spam أول مرة)
- [ ] زر واتساب يفتح الرسالة جاهزة
- [ ] الدخول للوحة بحسابك، والخروج
- [ ] https://yourdomain.com/config.php يعطي Forbidden أو صفحة فاضية، مش كود
- [ ] install.php اتحذف

## حماية مدمجة
- استعلامات SQL محضّرة، وكل النصوص المعروضة في اللوحة مُعقّمة من XSS.
- حماية CSRF على كل أوامر اللوحة، وجلسات HttpOnly.
- حد للطلبات: 5 طلبات لكل IP كل 10 دقائق، وحد لمحاولات الدخول: 8 كل 15 دقيقة.
- حقل مخفي لصيد البوتات.
- المنطقة الزمنية: التواريخ تتخزن UTC وتظهر بتوقيت القاهرة.

## مشاكل شائعة
- **خطأ 500 / صفحة بيضاء:** افحص بيانات `config.php`، وأن نسخة PHP 8.0 أو أحدث (hPanel → Advanced → PHP Configuration).
- **"تعذّر الاتصال بقاعدة البيانات":** اسم القاعدة أو المستخدم بدون البادئة u123456789_ غالبًا.
- **الإيميل مش بيوصل:** تأكد أن `mail_from` إيميل حقيقي على نفس الدومين. الطلبات في اللوحة محفوظة حتى لو الإيميل فشل.
- **زر الإرسال يعطي خطأ:** افتح الموقع عبر https، وتأكد أن مجلد `api` مرفوع.
- **نسيت كلمة سر الأدمن:** من phpMyAdmin احذف صف المستخدم من جدول `admins`، واحذف `install.lock`، وارفع `install.php` من جديد.
